# aiditi
AiDiTi — Angela Di Tomaso. Multimedia art, drawing, moving image and live performance.

## Artwork pages
`node build.mjs` generates a dedicated `/work/<slug>/` page for each existing work. Gallery links preserve the selected language; project pages reuse the translated descriptions and support images/GIFs plus video embeds. Optional `media` entries may be image URL strings or objects containing `src`, `alt`, `caption`, and `type: "video"` for direct video files.

All 39 existing works are retained. Additional media, detailed new descriptions, and decisions to remove work require Angela's supplied material/selections. No artwork data was deleted in this update.
